Інформація облікового запису

Як зареєстрований користувач, ви можете:

  • Створювати власну колекцію Dataverse, якщо дозволено, та налаштовувати її.
  • Додавати набори даних у колекції Dataverse, якщо дозволено.
  • Робити внесок у наявні набори даних, якщо дозволено.
  • Запитувати доступ до файлів з обмеженим доступом, якщо дозволено.

Варіанти входу до облікового запису

Інсталяцію Dataverse налаштовано для одного або кількох наведених нижче варіантів входу:

  • Ім'я користувача/Електронна пошта та пароль
  • Інституційний вхід (Institutional Log In)
  • ORCID
  • Microsoft Azure AD
  • GitHub
  • Google

Зверніть увагу: після створення облікового запису Dataverse він буде пов'язаний лише з одним із наведених вище варіантів входу.

Варіанти інституційного входу, ORCID, Microsoft, GitHub та Google детальніше описано нижче у розділі "Віддалена автентифікація".

Створення облікового запису

Щоб створити обліковий запис у системі Dataverse за допомогою Імені користувача/Електронної пошти, скористайтеся сторінкою "Sign Up" (Реєстрація). Заповніть поля та натисніть кнопку "Create Account" (Створити акаунт). Зверніть увагу, що поле "Ім'я користувача" (Username) не підтримує адреси електронної пошти, але дозволяє наступні символи: a-Z, 0-9, _ (підкреслення), - (дефіс) та . (крапка).

Щоб створити обліковий запис Dataverse, пов'язаний із варіантом входу вашої установи, ORCID, GitHub або Google, скористайтеся сторінкою "Log In" (Вхід) і виберіть одного з провайдерів автентифікації. Дивіться розділ "Віддалена автентифікація" нижче для більш детальної інформації.

Редагування облікового запису

  1. Щоб відредагувати свій обліковий запис після входу в систему, натисніть на назву свого облікового запису в заголовку праворуч і виберіть "Account Information" (Інформація про обліковий запис).
  2. У верхньому правому куті сторінки вашого облікового запису натисніть кнопку "Edit Account" (Редагувати обліковий запис), після чого ви зможете вибрати редагування або інформації облікового запису, або пароля.
  3. Виберіть "Save Changes" (Зберегти зміни), коли закінчите.

Зауважте, що ви не можете редагувати інформацію свого облікового запису в Dataverse, якщо ви використовуєте інституційний вхід. Замість цього вам слід звернутися до своєї установи, щоб змінити ваше ім'я, електронну адресу тощо. Як тільки зміни будуть внесені вашою установою, вони відобразяться в системі Dataverse під час вашого наступного входу в систему. Користувачі варіанту інституційного входу не зобов'язані підтверджувати свою адресу електронної пошти, оскільки установа, що надає цю адресу, є довіреною.

Конвертація облікового запису

Якщо доступно більше ніж один варіант входу, ви можете перейти від одного до іншого і використовувати новий варіант у майбутньому.

Якщо ви переходите з варіанту логіна Email/Username, вам потрібно буде мати свій пароль під рукою для завершення процесу конвертації. Натисніть "Вхід", виберіть новий варіант входу та пройдіть процес входу. Після повернення до Dataverse знайдіть опцію конвертації та введіть свій пароль для завершення. У розділі про віддалену автентифікацію нижче міститься більш детальна інформація щодо переходу на Institutional Log In, ORCID, GitHub та Google.

Якщо вам потрібно здійснити будь-яку іншу конвертацію (наприклад, з Google на GitHub), скористайтеся посиланням "Support" (Підтримка) вгорі сторінки для отримання допомоги.

Скидання пароля облікового запису

Лише в облікових записах Dataverse, які використовують варіант входу Ім'я користувача/Email, зберігається пароль (безпечно!) в системі Dataverse. Якщо ви не можете згадати цей пароль, натисніть "Log In" (Вхід) у верхньому правому куті будь-якої сторінки і натисніть посилання "Forgot Password?" (Забули пароль?) нижче під полем введення логіна та пароля. Введіть свою адресу електронної пошти та натисніть "Submit Password Request" (Надіслати запит на пароль), щоб отримати електронний лист із посиланням для скидання вашого пароля.

Зауважте, що якщо ви забули своє ім'я користувача (username), ви можете використати цей самий процес, щоб отримати його в електронному листі.

Віддалена автентифікація

Занадто багато паролів? Ви можете налаштувати свій обліковий запис у системі Dataverse на використання даних для входу від одного з наступних провайдерів віддаленої автентифікації. Таким чином, ви можете входити систему, використовуючи наявні облікові дані з іншого сервісу.

Інституційний вхід (Institutional Log In)

Інституційний вхід дозволяє вам використовувати ваші облікові дані для входу вашого університету (наприклад, HarvardKey в Гарварді) для входу до вашого облікового запису Dataverse.

Створення облікового запису Dataverse за допомогою інституційного входу

  1. Натисніть посилання "Log In" (Вхід) у панелі навігації.
  2. Виберіть кнопку "Your Institution" (Ваша установа) під заголовком "Other options" (Інші параметри).
  3. Використовуючи спадне меню, виберіть свою установу і натисніть кнопку "Continue" (Продовжити), щоб перейти на сторінку входу вашої установи.
  4. Після успішного введення ваших інституційних облікових даних ви повернетеся до Dataverse, щоб підтвердити дані свого облікового запису, і натисніть "Create Account" (Створити акаунт).
  5. Ім'я користувача буде обрано для вас автоматично. Ви не використовуватимете це ім'я користувача для входу, але воно з'явиться поруч з вашим ім'ям, коли інші користувачі шукатимуть вас, щоб надати дозволи в системі. Щоб побачити, яке у вас ім'я користувача, натисніть на своє ім'я у верхньому правому куті та натисніть "Account Information" (Інформація про обліковий запис).

Якщо ви не можете знайти свою установу у великому списку, вам може знадобитися подати запит на її додавання до категорії "Research & Scholarship" федерації ідентифікації. Див. "Усунення несправностей федеративного інституційного входу".

Якщо ваша установа є в списку, але ви отримуєте помилку входу ("eppn was null" або схоже), це може означати, що ваша установа задекларувала себе частиною категорії "Research & Scholarship" федерації ідентифікації, але вона не звільняє (release) обов'язкові атрибути (часто електронну адресу), як повинна. Щоб вирішити це, див. "Усунення несправностей федеративного інституційного входу".

Конвертація облікового запису Dataverse на використання інституційного входу

Якщо у вас уже є обліковий запис Dataverse, пов'язаний з варіантом Ім'я користувача/Email, але ви хочете конвертувати його на використання інституційного входу, ви можете легко це зробити, якщо ваш обліковий запис використовує електронну адресу від цієї установи.

  1. Перейдіть на сторінку Account Information, щоб переконатися, що електронна адреса вашого облікового запису збігається з вашою інституційною електронною адресою. Якщо ні, вам потрібно буде оновити обліковий запис, щоб вони збігалися.
  2. Вийдіть із системи Dataverse.
  3. Натисніть посилання "Log In" (Вхід) у навігаційній панелі.
  4. Виберіть кнопку "Your Institution" (Ваша установа) під заголовком "Other options".
  5. Використовуючи спадне меню, виберіть свою установу, а потім натисніть "Continue", щоб перейти на сторінку входу вашої установи.
  6. Після успішного введення ваших інституційних даних ви повернетеся до Dataverse, щоб підтвердити інформацію про ваш акаунт.
  7. Введіть ваш поточний пароль від облікового запису Dataverse і натисніть "Convert Account" (Конвертувати акаунт).
  8. Тепер ви завершили конвертацію вашого облікового запису Dataverse на використання інституційного входу.

Зверніть увагу, що ви не можете пройти цей процес конвертації, якщо ваш обліковий запис Dataverse, пов'язаний із варіантом Username/Email, був деактивований.

Відв'язування облікового запису від інституційного входу

Якщо ви залишаєте свою установу і вам потрібно конвертувати ваш обліковий запис Dataverse на використання варіанту Username/Email, вам потрібно буде звернутися до служби підтримки інсталяції Dataverse, яку ви використовуєте. На вашій сторінці акаунту є посилання, яка відкриє спливаючу форму для зв'язку з підтримкою.

Усунення несправностей федеративного інституційного входу

Dataverse може бути налаштована для інституційного входу через всесвітню федерацію (eduGAIN), але для успішного входу повинні передаватися (released) наступні атрибути Research & Scholarship (R&S):

  • Shib-Identity-Provider
  • eppn
  • givenName
  • sn
  • email

Якщо ви намагалися ввійти, але бачите помилку штибу The SAML assertion for "eppn" was null, вам потрібно буде звернутися до людей, які керують системою входу (Identity Provider або IdP) вашої організації, і пояснити, що вищевказані атрибути мають бути передані. Ви можете дати їм посилання на цей документ, а також на https://refeds.org/category/research-and-scholarship та розділ "Identity Federation" у посібнику з інсталяції.

ORCID Log In (Вхід через ORCID)

Ви можете налаштувати свій обліковий запис Dataverse, щоб дозволити вхід за допомогою ваших облікових даних ORCID. ORCID® - це незалежна некомерційна ініціатива для забезпечення відкритого реєстру унікальних ідентифікаторів дослідників та відкритих сервісів для зв'язування дослідницької діяльності та організацій з цими ідентифікаторами. Дізнайтеся більше на orcid.org.

Створення облікового запису за допомогою ORCID

  1. Натисніть посилання "Log In" у навігаційній панелі.
  2. Виберіть кнопку "ORCID" під заголовком "Other options".
  3. Натисніть кнопку "Log In with ORCID", щоб перейти на вебсайт ORCID.
  4. Якщо у вас ще немає акаунту ORCID, ви можете створити його на цій сторінці. Якщо є, натисніть "Sign in" та введіть свої дані на вкладці "Personal account".
  5. Після успішного введення облікових даних ORCID ви повернетесь у Dataverse, щоб підтвердити створення вашого акаунту. Якщо налаштування приватності вашого ORCID дозволяють це, електронна адреса з ORCID буде запропонована вам як опція. Ви можете використати її або будь-яку іншу адресу. Якщо ви ввели дані про своє працевлаштування у профілі ORCID, назва вашого роботодавця буде запропонована для поля "Affiliation" (Приналежність).

Конвертація облікового запису на використання ORCID

Якщо у вас уже є обліковий запис Dataverse з варіантом входу Username/Email, але ви хочете змінити його на вхід через ORCID, виконайте наступні кроки:

  1. Вийдіть із системи Dataverse.
  2. Натисніть "Log In" у навігаційній панелі.
  3. Натисніть кнопку "ORCID" під заголовком "Other options".
  4. Натисніть кнопку "Log In with ORCID", щоб перейти на сайт ORCID.
  5. Увійдіть до свого облікового запису ORCID.
  6. Після успішного входу ви повернетесь до Dataverse. Натисніть посилання "convert your account" (конвертувати ваш акаунт).
  7. Введіть свій логін і пароль від облікового запису Dataverse та натисніть "Convert Account".
  8. Тепер ви завершили конвертацію свого облікового запису Dataverse на використання ORCID.

Відв'язування облікового запису від ORCID

Якщо ви більше не хочете входити в Dataverse за допомогою ORCID, ви захочете перевести свій профіль на використання логіна Username/Email. Щоб зробити це, вам необхідно звернутися до служби підтримки інсталяції Dataverse. На вашій сторінці облікового запису є посилання, що відкриває спливаючу форму для звернення за допомогою.

Вхід через Microsoft Azure AD, GitHub та Google

Ви також можете перевести ваш обліковий запис Dataverse на використання автентифікації від GitHub, Microsoft або Google. Ці параметри можна знайти в розділі "Other options" на сторінці входу, і вони працюють аналогічно до того, як описано вище для ORCID. Якщо ви хочете перевести свій обліковий запис з використання одного з цих сервісів до стандартного, ви можете слідувати тим самим крокам, що і для відмови від входу через ORCID.

Зв'язування ORCID з вашим профілем облікового запису

Якщо ви ввійшли, використовуючи ORCID, Dataverse додасть посилання на ваш акаунт ORCID у вашому профілі, і коли ви створите набори даних, він автоматично додасть вас з вашим ORCID як автора.

Якщо ви входите іншими способами, ви можете додати посилання на свій обліковий запис ORCID під час створення облікового запису або пізніше через сторінку "Account Information" (Інформація облікового запису). Як і при використанні логіна ORCID, ви будете перенаправлені на сайт ORCID для входу там і забезпечення доступу для Dataverse. Після цього посилання на ваш ORCID відображатиметься на сторінці інформації про обліковий запис, і ваш ORCID буде додано як ваш ідентифікатор при створенні наборів даних (абсолютно так само, як якщо б ви увійшли через ORCID).

Зверніть увагу: можливість увійти через ORCID (або інших провайдерів) та можливість пов'язати свій профіль з ORCID є окремими параметрами конфігурації, доступними адміністраторам Dataverse.

My Data (Мої дані)

Розділ "My Data" на сторінці вашого облікового запису відображає перелік усіх колекцій Dataverse, наборів даних та файлів, які ви створили, завантажили, або на які у вас є призначена роль. Ви можете відфільтрувати їх на сторінці за допомогою вікна пошуку або за допомогою фасетів (фільтрів) ліворуч, щоб переглянути лише конкретний статус публікації (Publication Status) або роль (Role).

Примітка: Якщо ви бачите несподівані колекції або набори даних на своїй сторінці My Data, це може бути через те, що хтось призначив вашому обліковому запису роль у цих колекціях або наборах даних. Наприклад, деякі установи автоматично призначають роль "File Downloader" (Завантажувач файлів) на свої набори даних для всіх акаунтів, що використовують їхній інституційний вхід.

Ви можете використовувати кнопку "Add Data" (Додати дані) для створення нової колекції або набору даних. За замовчуванням нова колекція чи набір даних буде створена в кореневій колекції Dataverse, але у формі створення за допомогою випадаючого меню "Host Dataverse" ви можете вибрати іншу колекцію, до якої маєте доступ. Однак ви не зможете змінити цей вибір після створення.

Повідомлення (Notifications)

Сповіщення з'являються на вкладці сповіщень на сторінці вашого облікового запису, а також відображаються у вигляді числа поруч із вашим іменем. Ви також отримуєте повідомлення електронною поштою.

Якщо ваш адміністратор увімкнув можливість зміни налаштувань, ви знайдете їх огляд на вкладці сповіщень. Там ви можете вибрати, які повідомлення (в системі або електронною поштою) ви хочете отримувати. Якщо певні опції вимкнені (сірі), ви не можете їх змінити, бо адміністратор встановив їх як обов'язкові. Ви контролюєте системні повідомлення та email-сповіщення окремо у двох списках.

Зазвичай ви отримаєте повідомлення, коли:

  • Ви створили свій обліковий запис.
  • Ви створили колекцію Dataverse або додали набір даних.
  • Інший користувач системи Dataverse запросив доступ до файлів з обмеженим доступом у наборі даних, який ви опублікували. (Якщо ви відправили набір даних на розгляд і він був опублікований куратором, куратори колекції отримають сповіщення про такі запити доступу).
  • Файл в одному з ваших наборів даних успішно пройшов процес обробки (ingest).

Існують і інші типи повідомлень: про призначення ролей, створення ключа API тощо. Ці типи сповіщень є менш поширеними і не описані тут. Деякі обмежені ролями (напр. рецензенти (reviewers) отримують сповіщення, коли набір подано на розгляд).

Сповіщення дублюються на email лише один раз, навіть якщо ви їх ще не прочитали у системі.

Керувати повідомленнями можна і через API. (Див. API Guide).

API Токен (API Token)

Що таке API і чому вони корисні

API означає "Application Programming Interface" (Інтерфейс програмування додатків), і API програмного забезпечення Dataverse дозволяють вам користуватися інтеграціями з іншим програмним забезпеченням, що могли налаштувати адміністратори. Див. посібник для адміністраторів у розділах "External Tools" та "Integrations".

Крім того, якщо ви бажаєте написати трохи коду (або знайти когось, хто це зробить для вас), API надають спосіб автоматизувати частини вашого робочого процесу. Див. розділ "Getting Started with APIs" у посібнику по API для подробиць.

Як ваш API токен схожий на пароль

У багатьох випадках, наприклад, при депозитуванні даних, потрібен API Token для взаємодії з API Dataverse. Слово "токен" означає послідовність літер та цифр, наприклад, c6527048-5bdc-48b0-a1d5-ed1b62c8113b. Будь-хто, у кого є ваш API Token, може додавати чи видаляти дані від вашого імені, тому слід ставитись до нього з такою ж обережністю, як до пароля.

Як створити свій API Token

Щоб створити ваш API токен, натисніть на назву свого облікового запису у навігаційній панелі, потім виберіть "API Token" у випадаючому меню. У цій вкладці натисніть "Create Token".

Як перестворити (Recreate) ваш API Token

Якщо ваш API Token був скомпрометований або закінчився його термін дії (expired), натисніть на назву свого облікового запису у верхньому меню і виберіть "API Token" з меню. У цій вкладці натисніть "Recreate Token".
