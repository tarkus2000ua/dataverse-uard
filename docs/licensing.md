# Ліцензії даних і метаданих UaRD

Для Dataverse 6.12 застосовуються два окремі правила:

| Об’єкт | Ліцензія | Зміна користувачем |
| --- | --- | --- |
| Дані нового набору | CC BY 4.0 за замовчуванням | Можна вибрати іншу доступну ліцензію через штатне редагування умов |
| Метадані будь-якого набору | CC0 1.0 | Не передбачена |

## Налаштування типової ліцензії даних

Типова ліцензія зберігається в базі Dataverse і не переноситься з Git.
Використовуємо штатний `/api/licenses`, без зміни Java чи SQL.

Перегляд поточного стану, без автентифікації та змін:

```bash
python3 scripts/customization/configure-licenses.py --url http://localhost:8080
```

Застосування з наявним API-токеном суперкористувача у файлі:

```bash
python3 scripts/customization/configure-licenses.py \
  --url http://localhost:8080 --apply --token-file /path/to/admin-token
```

Для іншого сервера вкажіть його HTTPS URL і його токен. Саме збереження
скрипта не змінює налаштування віддалених серверів. Альтернатива файлу токена —
змінна середовища `API_TOKEN`; не вставляйте токен у команду чи Git.

Скрипт знаходить CC BY 4.0 за URI, незалежно від її числового ID. Якщо запис
відсутній, додає стандартне визначення з `scripts/api/data/licenses/`; якщо
неактивний, активує. Потім задає та перевіряє типову ліцензію. Повторний запуск
не змінює вже правильне налаштування. Інші ліцензії залишаються доступними.

Наявні набори, їхні чернетки та шаблони не переписуються. Шаблон із явно заданою
ліцензією зберігає її: за потреби адміністратор редагує такий шаблон окремо.
Явний вибір ліцензії через UI або API має пріоритет над типовим значенням.
Дозволені ліцензії конкретного типу набору також визначаються штатними правилами.

## Фіксоване правило для метаданих

У `dataset-license-terms.xhtml` для перегляду, редагування умов і шаблонів
показується окремий рядок «Ліцензія метаданих — CC0 1.0». Це текст із посиланням,
без поля введення, JSF binding, запису в базі чи параметра API. Ліцензія даних
над ним зберігає стандартний список вибору, права доступу та обробники Dataverse.
Тексти в `propertyFiles/UardLicensing*.properties` підтримують `en`, `ua` і `uk`
та використовують поточну локаль JSF.

Штатний `license` у JSON, DataCite, Schema.org та інших експортерах описує
ліцензію **даних**, тому його не підміняємо CC0. Поле зміни ліцензії метаданих
не додається ані в UI, ані в API.

Для встановлення UI потрібні `dataset-license-terms.xhtml` і три файли
`UardLicensing*.properties` у `WEB-INF/classes/propertyFiles/`, після чого
виконується звичайне розгортання. Для локальної перевірки вихідних змін
використовуйте FRD. Окремо виконайте скрипт налаштування для цільової інсталяції.
