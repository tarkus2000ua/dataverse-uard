# Видимість API на першому етапі запуску UaRD

На першому етапі звичайні користувачі працюватимуть із репозитарієм через
вебінтерфейс. У ньому приховано матеріали й елементи керування, які
пропонували самостійно працювати з API.

| Де | Що приховано |
|---|---|
| Меню користувача та особистий кабінет | Пункт і вкладку «Токен API», посилання на документацію, перегляд токена та дії з ним. Пряме посилання для звичайного користувача відкриває інформацію про обліковий запис. |
| Сповіщення | Записи про створення токена, цей пункт у налаштуваннях сповіщень і його внесок у лічильник непрочитаних. |
| Реєстрація та перший вхід | Пункт про використання API й посилання на окремі умови API українською та англійською. Прямі адреси цих двох сторінок тимчасово закрито. |
| «Про репозитарій» | Згадки про API в українському та англійському описах. |
| Український посібник | Розділ про токени й інструкції з програмного пошуку, керування сповіщеннями, завантаження через URL, отримання відповідей гостьової книги та скасування обробки табличних файлів через API. |
| Сторінки файлів і наборів даних | Адреси програмного завантаження та посилання на API у попередженні про перевищення ліміту ZIP. У діалозі для файлу-пакета замість адреси є кнопка завантаження. |
| Налаштування файлів | Пункти зовнішніх інструментів налаштування файлів, які можуть створювати токен API. Старі тестові сторінки API також тимчасово закрито. |

Суперкористувачі зберігають доступ до власних токенів і адміністративних
підказок. Адміністратори колекцій зберігають права керування колекціями.
Звичайне завантаження, експорт метаданих та робота чинних інтеграцій
зберігаються. Обмеження стосується видимості API у вебінтерфейсі.

Для наступного етапу повні тексти й елементи інтерфейсу збережено.
Відновлення потребує зміни одного параметра Dataverse та публікації
повної версії посібника. [Інструкція для адміністратора](api-launch-visibility.md).
